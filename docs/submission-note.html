1 / Why the chart is truthful

A dedicated Web Worker owns numeric Float64 columns. Steps are sorted numerically; the last received duplicate wins, even if invalid. NaN and Infinity produce null gaps, never zero. Missing training steps also break the line. Per step bucket, first/last/min/max measurements are retained in their original order, independently for loss, learning rate and gradient norm. No smoothing or averaging is enabled.

The single loss spike is 9.4 at step 500,000. It survives every tested viewport containing it. Hover is explicitly labeled sampled; it displays an actual retained value. Precise step ranges and zoom expose detail. Log mode discloses excluded nonpositive samples and keeps a linear alternative. CSV is clearly a sampled viewport, including blank gap entries.

2 / Executed checks

41 unit tests + 13 production-browser scenarios passed. TypeScript, ESLint and production build passed; dependency audit: zero known vulnerabilities. Automated axe WCAG 2 A/AA checks on the inspected desktop/mobile screens: zero violations, without claiming full accessibility certification.

Unit tests exercise the million-point spike across six widths and six ranges, extrema/source-value identity, non-finite values, duplicate/order/gap rules, invalid latest values, zero handling, exact statistics, worker races/abort/recovery, numeric labels and UTC rollover. Browser tests independently inspect painted Canvas spike pixels at overview, narrow and three-point zoom; check visible NaN gaps, log warnings, quick switching, loading, retry, CSV, keyboard controls and mobile overflow.

Limits: these tests do not prove scientific validity, live-cluster correctness, every possible dataset/zoom, screen-reader usability or physical-device ergonomics. A subpixel gap may be invisible in an overview; counts disclose missingness. Extrema lines can exaggerate dense oscillations; zoom is needed for detailed interpretation.

5 / Silent failures checked

  • Staleness: all fixtures are explicitly static/synthetic. Recorded status is not a live feed. Reload preparation time never claims source freshness. First real-source priority: revision, ingestion timestamp and missing-value contract.
  • Run-switch races: query identity includes run/range/width; AbortSignal and request IDs discard late replies. Run identity changes remount details. Actual browser and out-of-order unit tests check isolation.
  • Locale / timezone: numeric step axes, explicit en-US values, UTC dates with offset/rollover tests. No timestamp is inferred from a training step.
  • False continuity: no smoothing; invalid/missing data breaks the line. Latest invalid values stay unavailable. A divergence fixture remains discoverable.
  • Logarithmic zeros: nonpositive rendered samples are excluded with an explicit count. Linear mode retains zeros. A fully invalid interval shows an empty chart instead of a healthy zero curve.

6 / What surprised us, and AI assistance

A plausible status-based sparkline was the easiest false data claim; it was removed. Duplicate removal also initially masqueraded as reordered data. Independent consistency checks exposed both. Dense extrema sampling still compresses timing and can hide the physical width of a gap; representative real telemetry and operator review are the next meaningful checks.

Codex and Frontend Workbench assisted design, implementation and independent reviews. Accepted: uPlot, workers, extrema sampling, explicit fixture provenance and UTC. Corrected/rejected: fabricated trends, CSS-variable Canvas colors, colliding axis labels, metadata counts and retrying a stalled worker. Executed tests, browser rendering and Chrome traces verified the result; no human or real-cluster acceptance is claimed.
