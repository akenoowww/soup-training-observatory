1 / What is kept, and what is discarded

Twenty deterministic runs include NaN/Infinity, duplicates, unordered steps, missing steps, zeros, divergence and a 1M-point run. Source steps must be nonnegative safe integers; unsupported rows are rejected and counted. Numeric sorting uses the last received duplicate, including invalid latest values.

A worker retains four Float64 columns (32 MB at 1M). Exact viewport bounds precede first/last/min/max selection in each finite segment and step bucket. No averages or smoothing are used. Invalid values and absent steps break the line. Sign boundaries are retained before reduction, so log masking also breaks at every nonpositive interval. A unique spike survives selection in every containing viewport by construction; isolated finite points get visible markers. Constant zero lines are padded inside the plot rather than clipped at its edge.

Hover and CSV identify sampled observations. Statistics use all unique rows in view; pending/failed ranges show unavailable statistics. Dense timing and lesser peaks within one bucket are discarded. Subpixel gaps can be visually tiny, so missingness counts remain visible. Pathologically many gaps or sign changes exceed the ordinary output budget and remain a declared workload limit.

2 / Executed evidence, including failures

80 unit tests; 46 scenarios × 3 engines = 138 browser executions passed, without skipped/flaky results. Chromium, Firefox and WebKit ran against the production bundle on macOS. Independent oracles exercise 128 malformed streams, 1,152 dataset/range/metric combinations and 105 outlier/boundary cases.

Browser checks inspect actual Canvas spikes, NaN breaks, singleton/zero lines and drawn axis labels/coordinates. They control real Worker reply order through React/query/client, test stale/malformed responses, loading/error scope, drag/reset, keyboard focus, storage, UTC+14/Russian locale, 320/390/768px, DPR2 and touch emulation. Fifteen axe states have zero confirmed violations; mobile-dialog background estimates remain incomplete, with 31 nodes independently checked at contrast 5.27–13.25:1.

A long run found a serious defect after short tests passed: custom cache eviction removed a new query during observer attachment, retaining responses and growing memory to about 495 MB. The mechanism was removed in favor of TanStack's lifecycle-aware 10-second GC. A real-observer regression failed at range 12 before the fix and passed 40 transitions afterward; the UI regression completes 20 viewports with exactly 20 Worker requests per engine. Original failed tests, allocation samples and rejected-build measurements remain in evidence/round2/.

4 / Silent failures and sustained use

  • Staleness: immutable source revision and recorded time stay separate from view preparation. Old revisions and impossible chronology fail closed; reload never claims new training observations.
  • Races: run/revision/range/width identify queries, and a response retains its producing viewport. Late replies cannot populate a different run; prior same-run plots stay covered while updating.
  • Numbers: UTC and explicit numeric formatting are tested under other browser locales/zones. No smoothing hides divergence; log zero exclusions never become invented positive values.

The same final bundle completed 136 active cycles (546 counted actions) across all 20 runs, 180s activity plus 35s idle at normal CPU scheduling, with 0 browser errors. Retained page+worker V8/backing stores: 38.9 MB warm → 45.0 MB maximum checkpoint → 41.4 MB after idle (+2.5 MB net). Explicit GC includes worker source storage; this measures retained allocations, not unforced peak memory or absence of slower leaks.

5 / Surprise, concern, and AI use

The surprising failure was a correctly retained spike that Canvas did not paint when surrounded by gaps. Later, a cache “optimization” passed short tests yet caused runaway retention. The remaining concern is dense visual compression and workloads with extreme missingness. Physical-device ergonomics, screen-reader usability and exhaustive data/zoom coverage are not established by these tests.

AI tools: Codex and Frontend Workbench assisted architecture, implementation, tests and independent reviews. Accepted suggestions included uPlot, workers, extrema sampling and explicit source identity. Corrected or rejected: fabricated trends, mixed-scope summaries, invisible singleton/zero rendering, custom cache eviction and broad CPU/memory assumptions. Original failures remain in the repository.

Direct review: Codex directly inspected the sampling and Canvas-regression source, visually reviewed both rendered PDF pages, reconciled raw counts and memory/soak records, and parsed four timing plus four memory traces to verify Paint/EventDispatch events and recompute attributed renderer-private bytes. Automated unit, three-engine browser and Canvas suites provided the regression results separately from those direct source, document and evidence reviews.
